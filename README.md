# Hyper Studio Premium

Projeto em Next.js + React + TypeScript + Tailwind CSS + Framer Motion + Lucide React.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra http://localhost:3000

## Publicar na Vercel
1. Envie a pasta para o GitHub.
2. Importe o repositório na Vercel.
3. Framework: Next.js.
4. Deploy.
